# 验收清单（从零客户流程）

前置：Mac 已安装 oMLX 并启动过一次；StickS3 已烧 v0.2.1。

1. **清空设备**（可选，模拟新机）：串口发送 `RESET`，设备重启。
2. **配网**：屏幕出现二维码 → 手机连 `oMLX-Mate-XXXX`（密码 `omlxmate`）→ `http://192.168.4.1` → 选 2.4G Wi-Fi → 保存。
3. **拿到安装地址**：设备屏幕显示 `http://omlx-mate-xxxx.local`；Wi-Fi 图标、IP、电量正常。
4. **安装 agent**：Mac 打开该地址 → 点“复制命令” → 终端执行 → 安装脚本打印“安装完成”并打开控制台。
5. **出数**：设备 5 秒内从“连接 Mac”切到「今日已省」，数值与 `http://127.0.0.1:8789/` 一致（端口以 url.txt 为准）。
6. **翻页**：A 下一页、B 上一页；页脚圆点数量 = 控制台配置页数。
7. **改显示配置**：控制台加一页「成本」、调顺序、切「近 30 天」→ 保存 → 设备页数与内容随之变化。
8. **远程控制**：控制台点“›” → 设备翻页；点“重启” → 设备重启后恢复推送（不会反复重启）。
9. **语言**：控制台切 English → 设备文案变英文；切回中文。
10. **断线恢复**：`launchctl bootout gui/$(id -u)/com.omlx.mate` → 设备显示“延迟/离线”；重新 `launchctl bootstrap` 或重跑 setup → 自动恢复。
11. **卸载**：`curl -sL http://<设备>/uninstall.sh | bash` → 控制台/进程/LaunchAgent 消失；设备回到“连接 Mac”。

已知非阻断项：mDNS 偶发抖动（agent 会自动回退 IP）；控制台端口可能因占用顺延；OTA 一键升级未做。
